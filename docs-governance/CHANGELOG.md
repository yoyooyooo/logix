# Changelog

## v2 — Earned Shape

- Added independent layer, partition, and identity admission gates.
- Made flat internal organization and semantic paths the defaults.
- Added mixed, asymmetric, and reversible layer shapes.
- Clarified that child partitions inherit parent authority.
- Added `accepted-target` to distinguish adopted intent from current availability.
- Made `node_id` and atomic requirement IDs opt-in.
- Added structure-pressure auditing without automatic migration.
- Removed fixed assumptions that every project needs the same layers or numbering depth.
- Added evaluation cases for earned partitioning, flattening, and on-demand identity.
